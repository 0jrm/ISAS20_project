**Do not replace “ARGO target” with “L3 target.”**
Replace **L4 gridded satellite inputs** with **L3/L2-like observational inputs**, while keeping **ARGO/CORA/profile observations as the subsurface target**. L4 should become a teacher, auxiliary context, or augmentation source — not the thing the model is implicitly learning to trust as reality.

The attached response’s “smoothed-of-smoothed” critique is real: if ISAS20 is already an objective analysis of sparse profiles, and the surface inputs are also L4 optimal-interpolation products, the model can become a map-to-map smoother rather than a surface-observation-to-subsurface operator.  Copernicus explicitly describes its global L4 sea-level product as SLA estimated by optimal interpolation after merging L3 along-track altimetry, which is exactly the kind of smoothing chain you want to avoid making central. ([Copernicus Marine Data Store][1])

## My recommendation

The strongest dissertation design is:

> **Train a mask-native NeSPReSO variant that predicts ARGO/CORA subsurface profiles from sparse, irregular, quality-controlled surface observations: L3 along-track SSH, L3/L2P/L3U SST, 10 m wind history, optional SSS, and optional L4 context/augmentation with uncertainty-aware noise.**

This gives you a much better scientific claim than “I used cleaner gridded satellite maps.” The claim becomes: **the method remains useful under the observation geometry an operational system actually sees.**

## The key modeling change: make the model mask-native

Do **not** interpolate L3 into a fake complete L4-like image and feed that to the old model. That destroys the scientific point.

Instead, every surface variable should become a bundle:

| Channel type  | Meaning                                                                                       |
| ------------- | --------------------------------------------------------------------------------------------- |
| `value`       | Standardized observed value, filled with zero only after normalization.                       |
| `mask`        | 1 if observed, 0 if missing.                                                                  |
| `age`         | Hours since nearest observation for that cell/time bin.                                       |
| `uncertainty` | Sensor uncertainty, formal mapping error, retrieval uncertainty, or proxy.                    |
| `count`       | Number of observations aggregated into the grid cell.                                         |
| `source_id`   | Mission/platform identity if feasible: Jason, Sentinel-3A/B, SWOT, VIIRS-N20, VIIRS-NPP, etc. |

For your existing PatchConvMLP design, the minimal viable adaptation is:

```text
old input:
  [variable, time, y, x]

new input:
  [variable × feature, time, y, x]

where feature = value, mask, age, uncertainty, count
```

Then the first convolution sees not just “SSH is zero here,” but “SSH is missing here.” That distinction is existential.

## How to build samples

For each ARGO/CORA target profile at `(lat, lon, time)`:

1. Define a local patch, for example **±3° or ±5°** around the profile.
2. Define history bins, for example:

   * same day,
   * previous 1 day,
   * previous 3 days,
   * previous 7 days,
   * previous 14 days.
3. Rasterize all L3 observations into the local patch.
4. Aggregate observations per grid cell/time bin using inverse-variance weighting where uncertainty exists:

```python
weighted_value = sum(value_i / sigma_i**2) / sum(1 / sigma_i**2)
effective_sigma = sqrt(1 / sum(1 / sigma_i**2))
count = number_of_observations
age = target_time - observation_time
mask = count > 0
```

5. Store the tensor plus profile target.

The important design choice: **the raster grid is only a container for sparse observations; it is not an interpolated map.**

## L4 augmentation protocol

This is where your idea about using L4 uncertainty is useful, but it must be disciplined.

### Good use of L4

Use L4 to create **synthetic sparse observations**:

```text
L4 field → add noise using L4 uncertainty → apply real L3 mask geometry → train model to survive sparse/missing inputs
```

For SSH:

```python
x_aug = x_l4 + epsilon
epsilon ~ N(0, alpha * err_sla)
```

But do not use independent pixel noise only. Add spatially correlated perturbations too:

```text
epsilon = local_correlated_noise + iid_noise
```

because altimetry mapping errors are not pixelwise independent.

### Best augmentation set

| Augmentation               | Purpose                                                   |
| -------------------------- | --------------------------------------------------------- |
| Real-track masking         | Make L4 look like L3 observation geometry.                |
| Cloud-mask replay for SST  | Use real VIIRS/GHRSST missingness patterns.               |
| Mission dropout            | Remove one altimeter or SST sensor entirely for a sample. |
| Time-window dropout        | Remove the most recent day to simulate latency.           |
| Noise from uncertainty     | Teach the model not to overtrust L4/L3 values.            |
| Spatially correlated noise | Avoid unrealistic white-noise robustness.                 |
| Storm-aware augmentation   | Increase wind/SST perturbations during high-wind periods. |
| Coastal mask stress tests  | Test GoM shelf/slope/coast separately.                    |

### Bad use of L4

Avoid:

```text
L4 input → model → ISAS20 target
```

as the main training path. That is the smoothing-of-smoothing trap.

Acceptable:

```text
L4 input → pretraining / teacher / augmentation
real L3 + winds → ARGO target
```

## Experiments that need to be in the plan

You need an explicit ablation matrix. Otherwise you will not know whether L3 actually helped.

| Experiment                          | Input                                                       | Target       | Purpose                                           |
| ----------------------------------- | ----------------------------------------------------------- | ------------ | ------------------------------------------------- |
| A. Current baseline                 | L4 SSH/SST/wind                                             | ARGO or ISAS | Reproduce current model.                          |
| B. L4 + mask augmentation           | L4 fields with synthetic L3 masks/noise                     | ARGO         | Test whether robustness improves without real L3. |
| C. Real L3 only                     | L3 SSH + L3 SST + wind                                      | ARGO         | Honest operational-observation model.             |
| D. Real L3 + L4 context             | L3 observations plus L4 auxiliary channels with uncertainty | ARGO         | Test whether L4 helps without dominating.         |
| E. No wind history                  | Same as C/D minus wind                                      | ARGO         | Quantify value of 10 m wind history.              |
| F. No mask/age/uncertainty channels | Same values, no metadata                                    | ARGO         | Prove mask-native design matters.                 |
| G. L3 SSH only vs L3 SST only       | Separate modalities                                         | ARGO         | Understand what each surface sensor contributes.  |

Evaluation should be stratified by:

| Stratification                      | Why                                                               |
| ----------------------------------- | ----------------------------------------------------------------- |
| Distance to nearest altimeter track | Measures sensitivity to SSH sparsity.                             |
| SST cloud fraction                  | Measures robustness to missing thermal structure.                 |
| L4 `err_sla` / uncertainty bins     | Tests whether uncertainty-aware training works.                   |
| Loop Current / eddy regime          | GoM dynamics are regime-dependent.                                |
| Shelf vs slope vs deep GoM          | Different physics, different observability.                       |
| Wind-event intensity                | Tests whether wind history helps mixed-layer/subsurface response. |
| Season                              | Stratification and mixed-layer depth change strongly.             |

## Brutally honest take

This is probably **more scientifically valuable** than another architecture experiment. It also aligns better with your thesis story: assimilation readiness, uncertainty, missing observations, and operational realism.

But it is also dangerous if you let it sprawl. The minimum viable version should be:

1. **ARGO target.**
2. **L3 along-track SSH + ERA5 wind history.**
3. **Mask/age/count/uncertainty channels.**
4. **L4 SSH uncertainty augmentation.**
5. **Compare against the current L4-complete baseline.**

Only after that works should you add L3U SST, SMAP SSS, SWOT, or architecture changes.

The core hypothesis is clean:

> A NeSPReSO model trained with sparse, uncertainty-aware, mask-native L3 surface observations will generalize more honestly to operational conditions than one trained primarily on complete L4 gridded analyses.

That is a dissertation-grade claim.
